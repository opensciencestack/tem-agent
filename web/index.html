How the agent and the simulator are connected

HopWhat crosses it
page → demo_server.pyPOST /api/run with the loop, the dry-run flag and the host, then GET /api/state polling as the agent prints.
demo_server.py → tem_agent.pyinvoke_tem_ai_model(model_name="rule") on a background thread, with the agent's stdout captured line by line.
loop → rule_policy.pyget_next_action() returns the next tool call; each result goes back through post_tool_results().
loop → tem_capabilities.pyThe tool call itself. Every argument is checked against instrument_autoscript.yaml before anything reaches the instrument.
capabilities → connectorOne of two connectors: autoscript_connector.py for real hardware, mock_connector.py under --dry-run.
connector → simulatorautoscript_interface.py calls TemMicroscopeClient, which speaks the AutoScript framed protocol to 13.202.106.11:7521. No HTTP anywhere in this hop.
